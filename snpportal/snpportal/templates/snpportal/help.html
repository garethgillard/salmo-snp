Quick start

  1. Score SNPs: upload a VCF, SNP table, PLINK file or chip manifest, paste positions, or try an example. Or score the public variants of genes or intervals.
  2. Pick the trait preset (the tissues and stages that matter for your trait); you can switch it on the results page.
  3. Read the overview, filter the table, open a SNP's evidence card, and download the table as TSV.
  4. Without a list: search a gene (Ensembl name or id, NCBI LOC symbol, ortholog), an rs ID, a position or region, or browse the known loci.

Questions

Chromosome names

Use 1–29 as in Ensembl and AQUA-FAANG. Uploads and search also accept the aliases in the release's alias table{% if chrom_aliases %}, e.g. for chromosome 25: {{ chrom_aliases|join:", " }} (any case){% endif %}. The validation report lists every alias it applied.

My positions are on ICSASG_v2

Older chips and papers use ICSASG_v2. The portal needs Ssal_v3.1. Rows with an rs ID in their id column are moved for you: when a row's position is its rs ID's ICSASG_v2 position in EVA release 9, it gets the rs ID's Ssal_v3.1 position (alleles complemented where the strands differ; the results show position_source). Other positions: convert offline with prep/lift_icsasg_v2.py in salmo-snpscore. Every upload is checked: when more than {{ assembly_share }} of the SNPs checked against the genome have a reference mismatch or look strand-flipped, the upload QC warns that the list is probably on ICSASG_v2 or the other strand.

rs IDs and LOC symbols

Search finds rs IDs from EVA release 9 (rs IDs on several Ssal_v3.1 positions are left out) and opens their variant page; a file of rs IDs can be scored like any list. NCBI LOC symbols (LOC + the NCBI gene id) are found only for genes whose Ensembl description cites the NCBI gene, so many LOC genes still need their name, ortholog or position.

Chip manifests

Illumina manifests and Axiom annotation files are read as they are, but their positions are often on ICSASG_v2 and their alleles on the TOP/BOT or probe strand: watch the assembly warning and the ref_check column.

Blacklisted

ATAC peaks can't be called in blacklisted regions, so “no peak” there means “can't tell”, not “inactive”.

LORe

Late-rediploidized regions have a near-identical ohnolog copy, so genotyping probes may cross-hybridise.

A/T and C/G SNPs

These read the same on both strands, which some genotyping assays can't tell apart.

Privacy

Uploaded files are deleted as soon as they have been scored. From a VCF only CHROM, POS, ID, REF and ALT are read, so genotypes are never stored; other columns of a SNP table are kept with the results. Results are kept for {{ keep_hours }} hours and can be deleted sooner with Delete now; only people with the link can see them. The server never logs SNPs or file names. For confidential lists, run it locally. {% include 'snpportal/_badges.html' with kind='provisional' %}
