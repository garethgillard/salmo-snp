Confidential lists never need to leave your computer: snpscore with the same release and settings gives the same tiers as the portal. The portal keeps uploads for {{ keep_hours }} hours at most, but some lists are better not uploaded at all.

  1. Install snpscore (Python 3.8 or newer; its only dependencies are duckdb and pyyaml): 
    python3 -m venv snpscore-env
. snpscore-env/bin/activate
pip install "git+https://github.com/garethgillard/salmo-snp#subdirectory=snpscore"
  2. Get release {{ release.version }}. {% if zip %}Download release.zip from this portal's operator and check it: 
    shasum -a 256 release.zip   # must print {{ zip_sha256|default:"the sha256 in release.zip.sha256" }}
unzip release.zip -d {{ folder }}
    {% if release.sha256 %}Check that it is the same release as the portal's: 
    shasum -a 256 {{ folder }}/manifest.json   # {{ release.sha256 }}
    {% endif %} {% else %}Build it from the public sources (several GB of downloads), with the layers.yaml in the salmo-snp repository (snpscore/): 
    snpscore fetch
snpscore build --out {{ folder }}
    A downloadable release.zip with its sha256 comes later. {% if layers_sha256 %}Your manifest.json differs from the portal's (it holds the build date and your genome's path), so check the layers and the rules instead: both commands must print the value after the #. 
    {{ layers_check }}   # {{ layers_sha256 }}{% if weights_sha256 %}
shasum -a 256 {{ folder }}/weights.yaml   # {{ weights_sha256 }}{% endif %}
    {% endif %}{% endif %}
  3. Score your list (VCF, SNP table, PLINK .bim/.map or chip manifest), tiers for all 21 conditions as in the portal: 
    {{ command }}
    Add --threads 4 --memory 4GB to change DuckDB's limits, or -o my_snps.parquet for Parquet. Next to the output come .validation.json (the upload QC) and .rejects.tsv (rows not annotated).
  4. snpscore can also count one tissue's conditions only, with --trait: {% for name, label in cli %}{{ name }} ({{ label }}){% if not forloop.last %}, {% endif %}{% endfor %}. Those tiers differ from the portal's.

Every portal download starts with ‘#’ lines naming the release, the manifest and weights sha256 and the equivalent snpscore command, so a result can be reproduced and checked.
