The whole portal on your computer

  1. Install it (Python 3.11 or newer, in a fresh conda environment or venv): 
    pip install "git+https://github.com/garethgillard/salmo-snp#subdirectory=snpscore" \
            "git+https://github.com/garethgillard/salmo-snp#subdirectory=snpportal"
  2. Get the data once: release {{ release.version }} and the genome (about 1 GB), every file checked against its sha256: {% if data_url %}
    salmo-snp download
    {% else %}until it is hosted online, it comes as a GitHub Release of the repository: 
    curl -LO https://github.com/garethgillard/salmo-snp/releases/download/data-{{ release.version }}/salmo-snp-data-{{ release.version }}.tar
curl -LO https://github.com/garethgillard/salmo-snp/releases/download/data-{{ release.version }}/salmo-snp-genome-Ssal_v3.1.tar
tar -xf salmo-snp-data-{{ release.version }}.tar && tar -xf salmo-snp-genome-Ssal_v3.1.tar
salmo-snp download --from site
    {% endif %}
  3. Start it, then open http://127.0.0.1:8000/snp/ (only this computer can reach it): 
    salmo-snp serve

salmo-snp info shows where the data and your results are kept; they stay until you delete them.

From the command line

  1. Score a list (VCF, SNP table, PLINK .bim/.map or chip manifest) against a release folder (salmo-snp info prints it), tiers for all 21 conditions as in the portal: 
    {{ command }}
    Add --threads 4 --memory 4GB to change DuckDB's limits, or -o my_snps.parquet for Parquet. Next to the output come .validation.json (the upload QC) and .rejects.tsv (rows not annotated).
  2. snpscore can also count one tissue's conditions only, with --trait: {% for name, label in cli %}{{ name }} ({{ label }}){% if not forloop.last %}, {% endif %}{% endfor %}. Those tiers differ from the portal's.

A release you build yourself from the public sources (several GB of downloads; the salmo-snp repository's snpdata/ folder: snpdata fetch, snpdata build --out {{ folder }}) has its own manifest.json (build date, genome path){% if layers_sha256 %}; check its layers and the rules instead, both commands must print the value after the #: 
    {{ layers_check }}   # {{ layers_sha256 }}{% if weights_sha256 %}
shasum -a 256 "$(python3 -c 'import snpscore; print(snpscore.WEIGHTS)')"   # {{ weights_sha256 }}{% endif %}
    {% else %}.{% endif %}

Every portal download starts with ‘#’ lines naming the release, the manifest and weights sha256 and the equivalent snpscore command, so a result can be reproduced and checked.
