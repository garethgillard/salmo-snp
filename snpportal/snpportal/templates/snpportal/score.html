Coordinates must be Ssal_v3.1. Chromosomes are named 1–29 (aliases such as chr25 or ssa25 are mapped where the release supports it).

Your data

  • Your file is deleted as soon as it has been scored. From a VCF only CHROM, POS, ID, REF and ALT are read, so genotypes are never stored. Other columns of a SNP table are kept with the results: remove any you don't want stored.
  • Results are kept for {{ keep_hours }} hours, then deleted. You can delete them sooner with Delete now.
  • Only people with the results link can see them. We never log SNPs or file names.

For confidential lists, run it locally with the same release and commands.
